# 沉浸阅读浏览器测试

测试使用现有 Chromium，无需额外安装浏览器测试框架。Windows 会自动查找 Playwright 的 Chromium headless shell 缓存；其他位置或系统请设置 `CHROME_PATH` 为 Chromium 可执行文件路径。

先在一个终端运行 `pnpm build`，然后运行 `pnpm preview --host 127.0.0.1 --port 4321`。
在另一个终端运行 `node --test tests/immersive-reading/*.test.mjs`。

- `IMMERSIVE_TEST_URL`：可选，预览地址，默认 `http://127.0.0.1:4321`。
- `IMMERSIVE_SCREENSHOT`：可选，保存截图的绝对文件路径。
- 使用现有文章作为页面样本；至少需要两篇文章，其中一篇应包含 Markdown 标题。

测试覆盖首页与文章间的 Swup 导航、直接打开文章、进入/退出与焦点、Esc 与当前段落定位、左右及折叠目录、目录开关时正文始终居中且尺寸不变、真实目录跳转、空目录与解锁后内容更新、四种壁纸与两种主题、1024px 边界、默认进入与浏览器返回。

逐帧回归还检查正文主要移动及时开始、当前阅读段落没有明显单帧跳动、目录开关不创建正文变换，以及临时固定的外围卡片样式在结束后清理。

`long-article.test.mjs` 使用仓库内《福建之旅》的真实结尾，分别将末段开头和最后一个日期标题放在阅读窗口上方，记录进入、退出的每一帧，检查单帧位移和最终阅读位置。该文章需保留为回归样本。

过渡测试覆盖首页及文章初始加载不下载 GSAP、首次动画操作按需加载，以及进入/退出的 1.25s 时间轴、目录展开/折叠的 675ms 时间轴、读到新段落后退出仍保留该段落、正文逐帧尺寸与位置连续、目录动画全过程不移动或缩放正文、周围卡片实际淡出下沉、正文保持可见、完成后样式恢复、无原生 View Transition 时的行为、减少动态效果、Esc 与导航中断清理。每次进入时目录默认收起，手动展开后位于右侧。测试通过构建输出定位 GSAP 引擎代码块，需先完成构建。
