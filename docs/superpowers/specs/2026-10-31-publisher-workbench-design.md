# 博客工作台外观

用户已确认第一张横版概念图；1:1 图为误操作，忽略。「在浏览器预览」按钮文字缩小一号。

目标：安静的编辑器界面，预览优先，保留蓝色状态和红色问题提示。只改变插件工作台，不改变笔记编辑器或博客主题。

布局：标题与更多菜单 → 文章选择与发布状态 → 原笔记与更换入口 → 默认折叠的发布信息 → 预览工具栏 → 状态与问题 → 自适应 iframe → 底部发布按钮。

相比始终展开表单的布局，折叠表单让常用的浏览器预览入口与发布动作更容易找到。底部显示实际发布状态，不显示无法核实的「已保存」。窄屏允许工具栏换行，表单区域独立滚动，底部操作始终可见。

视觉规范：沿用 Obsidian 字体；正文 13px，浏览器按钮 12px，标题 17px；间距 6/10/14/18px；边框使用主题变量；状态使用蓝色，问题使用红色，并同时提供文字与图标。暗色主题使用相同层次。仅发布/更新按钮使用实心强调色。

交互：保留 metadata 字段、封面、记录选择、缺失文件关联、恢复、上线检查、下架确认、预览版本握手。更多菜单收纳绑定当前笔记与下架。首次无记录时展示明确的选择入口。详情展开状态在重新渲染时保留。问题定位使用真正的按钮，支持键盘。

检查重点：折叠信息不得隐藏错误；刷新不能提前启用发布；旧预览仍可在浏览器阅读；空记录不得留下旧按钮或旧预览；操作期间禁止切换目标和修改发布信息。
