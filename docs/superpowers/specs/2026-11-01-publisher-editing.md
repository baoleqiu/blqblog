# 图片排版、可选博客稿与窗口预览

用户已确认全部功能与三张横版设计图，授权实施。沿用白/浅灰、蓝色操作和红色问题提示；仅发布按钮使用实心强调色。

- 纸飞机仍打开左右分屏，绑定当前 Markdown；之后不会自动切换目标。没有博客稿时在左侧编辑原文。
- 图片面板自动列出文章中的图片，每处分别设置宽度（百分比/像素）、左中右对齐及图注；设置独立持久保存，不改原文或原附件，默认无需创建博客稿。保留原图放大与图片上下间距。
- 主动点击创建博客稿才在笔记库的博客稿/<文章编号>/目录生成 Markdown，附件共用但链接必须正确解析；正文独立，不随原文自动更新。同文章/网址不变，重开默认博客稿。切回原笔记保留稿件。
- 博客稿可在插件编辑文字、粘贴/拖入/选择图片、删除引用，也可用 VS Code 或系统默认编辑器打开。新增附件遵循 Obsidian 附件路径；删除引用不删除附件。文件外部修改要检测冲突，不静默覆盖。
- 不提供从空白新建独立文章或导入外部文章入口。
- 移除工作台内网站 iframe；打开工作台仍自动生成预览，后续变更最多每分钟自动刷新，手动刷新可立即执行。状态区显示真实阶段，不伪造百分比。
- 窗口预览是占屏约九成、可调整大小的原生 Obsidian 弹出窗口，非置顶；加载完成可显示同一预览服务的网页，刷新不重复构建；浏览器入口保留。窗口关闭不丢稿，工作台关闭清理自身服务与预览窗口。
- 发布仍需要最新快照校验；网页生成与可见窗口载入分别报告；不依赖已删除的小 iframe 才能发布。
- 旧数据无损兼容；发布期间禁止切换/编辑；稿件缺失、附件缺失、旧预览、外部修改都有明确反馈。
