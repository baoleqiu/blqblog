# 沉浸阅读

依据：https://docs-firefly.cuteleaf.cn/zh/guide/immersive-reading.html

用户已要求按该指南实现。沿用现有 Astro 组件、主题变量、悬浮按钮风格及 TOCManager；根据后续确认，引入按需加载的 GSAP 3.15.1 统一管理沉浸阅读过渡。

## 行为

- `siteConfig.post.immersiveReading` 提供 `enable: true`、`defaultOn: false`、`tocEnabled: true`、`tocPosition: "right"` 四项配置。
- 仅文章详情页、视口宽度至少 1024px 时显示入口；点击进入/退出，Esc 退出。进入与退出都保留切换时正在阅读的段落及其屏幕位置，退出不回到进入前的位置。
- 原文章卡片居中，背景和阅读面不透明，随浅色/深色主题变化。隐藏导航、壁纸、水波纹、渐变、侧栏、页脚、分类栏、评论、推荐、上下篇导航及装饰模型。
- 常驻目录支持左右位置，按用户最新要求默认收起，手动打开时显示在右侧；面板折叠按钮与悬浮目录按钮都可切换。正文始终相对窗口水平居中，目录开关及过渡均不改变正文位置或宽度；空间不足时目录悬浮覆盖正文，不为其挤压正文。
- 普通侧栏目录、悬浮目录和沉浸目录共用按需显示的滚动条：默认透明，仅在目录滚动区收到鼠标滚轮操作时显示，停止约 800ms 后淡出。保留滚动条占位避免内容跳动，重新初始化、收起目录、退出或切页时清除显示状态与计时器。
- 目录复用现有工具；加密文章解锁后重建，无标题文章显示现有空状态。按钮具有工具提示、键盘焦点与相应 ARIA 状态。
- 页面离开清理状态与目录观察器；进入下一文章重新应用默认值；缩小至移动端退出。切换布局不修改现有壁纸偏好。

## 方案

采用局部 CSS 状态及独立控制器，保留同一个正文 DOM，兼容媒体、公式、加密与 Swup。复制正文到弹层会破坏这些交互；整体升级模板会引入无关更改，因此不采用。

进入/退出采用单段连续移动：播放前完成布局测量及段落对齐，周围原有可见卡片暂时固定在原视口位置并同时退场，播放中不再重排页面。结束或中断时恢复临时样式。目录开关只处理目录卡片，不测量或变换整篇正文。

长文章的变换中心放在当前可见阅读点附近，避免以正文顶部为中心时，比例舍入误差被数万像素的距离放大。两个方向共用阅读定位工具，优先选取视口中可见的正文块开头；没有完整可见开头时保留部分可见块，变换中心仍限制在视口附近。

## 验证

2026-11-04 用户最新确认：进入/退出使用 1.25s、无弹跳的 GSAP 卡片过渡，目录展开/折叠维持 675ms。正文从现有位置和大小连续平移放大，周围卡片淡出下沉并完全隐藏；进入时只浮出正文，目录默认收起，由按钮手动打开。退出时卡片回到普通布局，视线仍停留在退出时阅读的段落，按钮颜色与主页按钮一致。首次动画操作时按需加载并缓存 GSAP 及 Flip；保留当前段落定位、减少动态效果及中断清理，下载失败时直接完成布局切换。隐藏规则只匹配初始化时标记的页面外围内容，避免误隐藏 GSAP 测量节点导致起始尺寸变为零。

真实 Chromium 浏览器测试入口、模式切换、滚动恢复、目录导航/折叠、1024px 边界、主题与壁纸、Swup 首页到文章/文章到文章/返回导航。执行格式检查、Astro 检查及生产构建；已有错误须与本次新增问题区分。
