# Immersive Reading Implementation Plan

**Goal:** 按 Firefly 沉浸阅读指南为当前博客增加可配置的桌面端专注阅读。
**Architecture:** 保留正文 DOM，用状态类重排现有布局；独立控制器处理按钮、目录与生命周期，复用 TOCManager。
**Tech Stack:** Astro 6、TypeScript、CSS、GSAP 3.15.1（按需加载）、Node.js 浏览器测试。
**Spec:** `docs/superpowers/specs/2026-11-03-immersive-reading-design.md`

## Global Constraints

- 1024px 起可用。默认 enable=true、defaultOn=false、tocEnabled=true、tocPosition=left。
- 沿用主题和国际化；保留原有文章、媒体及发布插件功能。
- 本次在已有工作区实现；保留用户现有未跟踪文件，不提交或部署。

## Review Focus

- Swup 从首页进入文章时入口能出现，离开文章状态不会泄漏。
- 带锚点加载、加密解锁、空目录不应导致异常。
- 所有壁纸与浅色/深色模式下阅读面均不透明。
- 收起目录、左右目录及 1024px 宽度时正文不与操作按钮重叠。
- 快速重复进入/退出、窗口缩小和导航不会留下滚动恢复回调或观察器。
